# Phase Shift（相位跳跃）

Phase Shift 是一款开源的 2D 动作 / 平台游戏，使用 **Godot** 引擎开发。游戏围绕“相位切换”这一核心机制展开，强调操作时机、关卡理解与策略选择。

## 核心玩法

玩家可以在两种相位之间自由切换：

* **实体相位（Physical Phase）**

  * 具备完整碰撞
  * 可以站立、攻击、触发机关
  * 会受到敌人与陷阱伤害

* **幽灵相位（Ghost Phase）**

  * 无实体碰撞，可穿越墙体与敌人
  * 无法攻击或触发大多数机关
  * 持续消耗相位能量

相位切换存在冷却与资源消耗，玩家需要在安全与风险之间做出权衡。

## 游戏目标

* 利用相位切换通过关卡
* 躲避或处理只在特定相位生效的敌人与机关
* 以更少的死亡、更少的切换完成关卡以获得更高评价

## 设计特点

* 规则简单但可深度组合的核心机制
* 关卡驱动的设计，逐步引入新元素
* 快速重生，鼓励尝试与学习
* 低数值依赖，强调操作与理解
